# Fractal Jigsaw Puzzles (POD)

A new POD product type in the "fractal jigsaw puzzle" niche (Etsy fav avg 268,
only ~106 competitors). Reuses existing high-res fractal masters (Julia set +
magnetic-pendulum), cropped 5:4, on Printify jigsaw puzzles — no new art.

## File
| File | What it does |
|---|---|
| `create_puzzles.py` | Crops masters to 5:4, upscales, and publishes puzzles on Printify blueprint 616 / provider 1 (SPOKE), 120 / 252 / 500 pieces, to the Etsy shop. |
