# Trigonometry — scientific-plate Set of 6 (digital)

Six classroom trig plates in the cream graph-paper / LaTeX "scientific plate"
house style (matches Special Functions & Famous Equations). Targets the
"trigonometry poster set" niche (Etsy score 76.1, only ~19 competitors, 81% digital).

## Files
| File | What it does |
|---|---|
| `generate_trig_plates.py` | Renders 6 plates (Unit Circle, Sine & Cosine, Right Triangle/SOHCAHTOA, Identities, Laws of Sines & Cosines, Tangent) at 12x18 300dpi, reusing `generate_equation_plates` helpers. |
| `build_listing.py` | Etsy previews (gallery hero, grid, singles, info) + 2:3 print files + 2 ZIPs; `--publish` creates the digital set-of-6 listing. |
