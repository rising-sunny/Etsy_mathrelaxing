## Competitive read

1. **Big gift/decor keywords are saturated (KD 100)** — use them as *one* title clause + 2–3 tags, not the whole listing.
2. **Win on long-tail:** `equation poster` (comp 151) + `schrodinger equation` (comp 78) + `quantum physics art` (306). Almost nobody owns these combinations.
3. **Set language is validated:** wall art set / gallery wall set / set of 6 prints all have measurable demand — keep “Set of 6” in title.
4. **Avoid “Schrödinger’s cat” as primary** — pop search, but our art is scientific plates, not meme cats (mismatch CTR risk).
