Semi-transparent background styles for Editorial resumes
========================================================

These PNGs are already embedded in the matching Editorial .docx files.
You can also insert them manually in Word:
  Insert → Header → Picture → pick bg_*.png
  Picture Format → Wrap Text → Behind Text
  Resize to full page (8.5 x 11 in).

Styles:
  cream_veil       soft cream wash + gold vignettes
  scientific_grid  whisper graph paper (MathRelaxing signature)
  gold_geometry    corner frames + soft circles
  phi_whisper      ultra-faint golden spiral
  navy_edge        left navy edge + gold hairline

ATS templates intentionally have NO background.
